# Public assets

Drop real images here and they replace the built-in gradient fallback art
automatically — no code change needed. Until a file exists, a colorful
on-brand cover renders in its place.

Expected paths (recommended format: `.webp`, ~1600px wide, optimized):

| Slot | Path |
| --- | --- |
| Work case-study covers | `/work/<project-slug>.webp` — e.g. `work/aurora-outfitters.webp` |
| Studio / team photo | `/studio/team.webp` |
| Studio location / map | `/studio/location.webp` |

Project slugs: `aurora-outfitters`, `meridian-health`, `northline-roasters`,
`basin-and-co`, `fernweh-travel`.
